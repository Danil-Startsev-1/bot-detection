# Классификация ботов по событиям Авито

## Окружение

Python 3.13.5.
Версии используемых open-source библиотек указаны в requirements.txt:
NumPy, pandas, scikit-learn, CatBoost и компоненты Jupyter.
Обучение и предсказание выполняются локально, без внешних API.

## Файлы

- quickstart.ipynb — анализ данных, эксперименты и финальное обучение.
- metric.py — официальная реализация метрики.
- requirements.txt — версии зависимостей.
- submission.csv — итоговые предсказания.
- data/train.csv, data/test.csv, data/events.csv.gz — исходные данные задания.

## Запуск

Откройте терминал в папке решения.
Создайте окружение на Python 3.13.5:

    python -m venv .venv

Активируйте его.

Windows PowerShell:

    .\.venv\Scripts\Activate.ps1

Linux/macOS:

    source .venv/bin/activate

Установите зависимости и запустите Jupyter:

    python -m pip install -r requirements.txt
    python -m notebook

Откройте quickstart.ipynb, выберите ядро созданного окружения
и выполните Restart Kernel and Run All Cells.
Ноутбук повторно запускает эксперименты, поэтому выполнение
может занять некоторое время.

Последние ячейки обучают итоговую модель на всём train
и сохраняют submission.csv в папку решения, перезаписывая
существующий файл с таким именем.

## Подход

События ограничиваются окном каждой куки; полные дубликаты удаляются.
Используются 56 признаков: характеристики активности, интервалы,
разнообразие объектов, глубина поиска, возраст куки и признаки клиента.

Итоговая модель — CatBoost:
depth=7, iterations=600, learning_rate=0.05, l2_leaf_reg=3.
random_seed=0, thread_count=1.

Модель выбрана по среднему Precision при Recall >= 70%
на двух временных периодах. Результаты: 0.4628 и 0.6284.
Периоды неоднократно использовались для выбора решения,
поэтому оценки могут быть оптимистичными.
